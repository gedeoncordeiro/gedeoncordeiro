## Projeto em Destaque

### [PseudocodePy](https://github.com/gedeoncordeiro/PseudocodePy)

Interpretador de pseudocódigo no padrão **VisualG** para ambientes Linux. O projeto nasceu da necessidade de oferecer a estudantes uma forma simples de executar algoritmos fora do ambiente Windows, reduzindo a barreira de entrada no aprendizado de lógica de programação.

- **Público-alvo:** estudantes e professores de Algoritmos e Lógica de Programação
- **Tecnologia:** Python
- **Plataforma:** Linux
